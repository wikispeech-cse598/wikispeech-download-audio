# Wikispeech Download Audio

An end-to-end implementation of downloadable audio articles for [Wikispeech](https://www.mediawiki.org/wiki/Extension:Wikispeech), the MediaWiki text-to-speech extension. A reader can go to a special page on a wiki, pick an article and a voice, and get back an `.opus` audio file of the article with a license/attribution intro prepended.

This repository is a companion to five patches we submitted to Wikimedia's Gerrit code review system. The patches themselves live in the upstream Wikispeech repository; this repo contains the design documentation, development notes, and a playable demo of the feature.

## What this project does

Wikispeech lets users listen to Wikipedia articles in their browser. Until now, listening required staying on the page — no offline, no podcast-app, no sharing. The "Download Audio" feature (umbrella task [T397023](https://phabricator.wikimedia.org/T397023)) extends this by letting users request a full-article audio file they can download, save, and play anywhere.

The feature is built from five separable pieces:

| Piece | Phabricator task | What it does | Gerrit patch |
|---|---|---|---|
| Download request API | [T402522](https://phabricator.wikimedia.org/T402522) | Accepts "I want a download of article X in voice Y" | [1270914](https://gerrit.wikimedia.org/r/c/mediawiki/extensions/Wikispeech/+/1270914) |
| Download announcement | [T403152](https://phabricator.wikimedia.org/T403152) | Synthesises the spoken license/attribution intro | [1270609](https://gerrit.wikimedia.org/r/c/mediawiki/extensions/Wikispeech/+/1270609) |
| Download job | [T407468](https://phabricator.wikimedia.org/T407468) | Background worker that assembles the audio file | [1271020](https://gerrit.wikimedia.org/r/c/mediawiki/extensions/Wikispeech/+/1271020) |
| Echo notification | [T402528](https://phabricator.wikimedia.org/T402528) | Notifies the user when their download is ready | (committed locally, pending design confirmation) |
| Special page UI | [T402526](https://phabricator.wikimedia.org/T402526) | User-facing page to submit and manage downloads | [1271979](https://gerrit.wikimedia.org/r/c/mediawiki/extensions/Wikispeech/+/1271979) |

All five together deliver the full feature: a user navigates to `Special:DownloadPageAudio`, picks an article and voice, clicks "Request new download," receives a notification when ready, and downloads an `.opus` file whose first ~15 seconds announce the article's source and license, followed by the article body.

## How to review our contribution

Our work is five patches on Wikimedia's Gerrit instance. To review any of them:

1. Click the Gerrit patch link in the table above
2. The Gerrit UI shows the full diff, commit message, reviews, and CI status
3. To check out a patch locally: each Gerrit change page has a "Download" button with `git` commands

Four of the five patches are visible publicly on Gerrit; the Echo notification patch (T402528) is committed locally pending Sebastian's confirmation on notification mechanism design.

## Demo

Two pre-generated audio files demonstrating the feature end-to-end:

- [`demo/demo-main-page.opus`](demo/demo-main-page.opus) — the default MediaWiki Main Page, ~42 seconds
- [`demo/demo-earth.opus`](demo/demo-earth.opus) — a test "Earth" page, length varies

Both files contain two Ogg streams: the first ~15 seconds is the license/attribution announcement, the rest is the article body. Any modern audio player handles the chained streams (VLC, mpv, ffplay, browser `<audio>` tags).

The announcement sounds like:
> "This audio version uses material from the my_wiki article 'Main Page', which is released under Creative Commons Attribution-ShareAlike 4.0. The audio was generated by Wikispeech, a text-to-speech extension for MediaWiki."

## Known follow-ups

These were identified during implementation and are documented but not patched:

- **Wiring DownloadAnnouncement into DownloadJob**: T403152 built the announcement class; T407468 was designed independently. Integrating them is a small follow-up patch. We wired them together locally for demo purposes (see [`docs/local-demo-wiring.md`](docs/local-demo-wiring.md)) and will file a Phabricator task after Sebastian's review of both parent patches.
- **Embedding license metadata in Opus Vorbis comments**: the spoken intro provides audible attribution, but the `.opus` file itself has no machine-readable license metadata. Opus supports Vorbis comment tags (TITLE, ARTIST, LICENSE, CONTACT); these could be added via `opusenc --comment` flags in the download job.
